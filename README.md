# 충곽에타 (CNSH EVERYTIME)

> **충남과학고등학교의 복잡한 하루를 한 화면에서 확인하세요.**  
> 등교 후부터 취침 전까지, 매일 확인하는 학교 생활 정보를 한곳에 모은 학생 전용 종합 포털입니다.

## 바로 사용하기

[충곽에타 바로가기](cnshtime.kro.kr)

> **첫 접속 안내**  
> 처음 접속 시 **이름과 학년·반**을 입력하면 사용 중인 기기의 브라우저에 저장됩니다.  
> 다음 접속부터는 선택한 반에 맞춘 개인화된 정보를 자동으로 보여줍니다.

## 주요 기능

| 기능 | 상세 설명 |
| :--- | :--- |
| **지금 일과** | 현재 진행 중인 수업/생활 일과 및 남은 시간 실시간 표시 |
| **오늘 시간표** | 선택한 학년·반의 수업을 현재 교시 중심으로 정렬해 제공 |
| **급식 안내** | 시간대에 맞는 조식·중식·석식 및 일주일 식단 정보 제공 |
| **방과후** | 학년·반과 날짜에 해당하는 방과후 수업 과목 확인 |
| **실시간 날씨** | 학교 주변의 현재 날씨 및 체감온도 정보 제공 |
| **공지사항** | 메인 화면 최신 공지 및 전체 게시판 연결 |
| **커뮤니티** | 충곽 학생 커뮤니티로 빠른 이동 |
| **시설 예약** | 학교 시설 예약 페이지 바로가기 제공 |

## 홈 화면에 추가하기 (PWA)

스마트폰 홈 화면에 추가하면 브라우저 주소 입력 없이 전용 앱처럼 사용할 수 있습니다.

<details>
<summary><b>iPhone · iPad (Safari 권장)</b></summary>

1. **Safari**에서 충곽에타 페이지 접속
2. 하단 중앙의 **공유 버튼** (네모 위로 화살표 모양 아이콘) 터치
3. 메뉴를 아래로 내려 **[홈 화면에 추가]** 선택
4. 이름이 `충곽에타`인지 확인 후 우측 상단 **[추가]** 터치
5. 홈 화면 생성 아이콘으로 바로 실행
</details>

<details>
<summary><b>Android (Chrome)</b></summary>

1. **Chrome**에서 충곽에타 페이지 접속
2. 우측 상단 **점 3개 메뉴** (`⋮`) 터치
3. **[홈 화면에 추가]** 또는 **[앱 설치]** 선택
4. 이름과 아이콘 확인 후 **[추가]** 또는 **[설치]** 터치
</details>

<details>
<summary><b>Samsung Internet</b></summary>

1. **Samsung Internet**에서 충곽에타 페이지 접속
2. 하단 우측 **메뉴 버튼** (`≡`) 터치
3. **[현재 페이지 추가]** 선택 ➔ **[홈 화면]** 선택
4. 이름 확인 후 **[추가]** 터치
</details>

## 이용 팁 & FAQ

* **반 정보 변경:** 학년이나 반이 바뀐 경우, 화면 내 **학년·반 선택 메뉴**에서 언제든지 다시 설정 가능합니다.
* **화면 갱신:** 정보가 즉시 업데이트되지 않는다면 페이지를 한 번 **새로고침**해 주세요.
* **아이콘 오류:** 홈 화면 아이콘이 이전 모습으로 표시될 경우, 기존 바로가기를 삭제한 뒤 다시 추가해 주세요.
