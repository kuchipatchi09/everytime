# asterisk* Planetarium Observatory (독립 플라네타리움 테스트 환경)

asterisk의 실시간 천체 시뮬레이션(태양, 달, 은하수, 황혼, 인공위성 등)을 메인 대시보드와 독립하여 단독으로 실행하고 테스트할 수 있는 독립형 플라네타리움 환경입니다.

---

## 🚀 실행 방법

### 방법 1. 루트 프로젝트에서 실행 (가장 간편)

루트 디렉토리(`cnsh-eta`)에서 아래 명령어를 실행합니다:

```bash
# astronomy-test 독립 개발 서버 실행 (포트 5174 자동 오픈)
npm run dev:astronomy
```

또는 루트 개발 서버(`npm run dev`)가 켜져 있는 상태에서 브라우저로 접속:
- `http://localhost:5173/astronomy-test/`

---

### 방법 2. astronomy-test 폴더에서 독자적으로 실행

```bash
cd astronomy-test
npm run dev
```

브라우저가 자동으로 열리며 `http://localhost:5174/`에서 실행됩니다.

---

## 🌟 주요 기능 및 인터페이스

1. **실시간 천체 하늘 렌더링 (1:1 실시간 동기화)**
   - **태양 (Sun)**: 위도/경도 기반 일출, 일몰, 남중고도 계산, 6종 동적 렌즈 플레어 및 애너모픽 광원 스트릭 렌더링.
   - **달 (Moon)**: 신월 에포크(New Moon Epoch) 기반 정확한 29.53일 삭망월 월령 계산, 초승달~보름달~그믐달 수학적 SVG Path 렌더링, 지구조(Earthshine) 및 달무리(Lunar Aura).
   - **은하수 및 별빛 (Milky Way & Stars)**: ESO Serge Brunier 360도 전천 파노라마를 지방항성시(LST) 및 경도에 맞춰 실시간 천구 회전 투영.
   - **황혼 대기 산란 (Twilight Blending)**: 시민박명, 항해박명, 천문박명에 따른 대기색 그라데이션 및 별빛 마스킹.
   - **인공위성 통과 (Satellites & Starlink)**: 야간 시간에 무작위 궤도로 통과하는 인공위성 및 스타링크 편대(14기) 비행 애니메이션.

2. **24시간 인터랙티브 타임라인 스크러버**
   - 00:00부터 24:00까지 자유롭게 드래그하여 하루 중 원하는 시각의 밤하늘과 일출/일몰을 즉시 탐색.
   - 1x(실시간), 10x, 60x(1초=1분), 300x(1초=5분), 1800x(1초=30분 타임랩스) 배속 조절.
   - **새벽, 일출, 남중, 일몰, 황혼, 자정, 현재시각 동기화** 퀵 점프 버튼.

3. **☁️ 실사형 20단계 구름 시뮬레이터 (Cloud Coverage & Types)**
   - **0(완전 쾌청)부터 20(칠흑 비구름)까지 20단계 기상학적 운형 분화**:
     - `0`: 청명 (Clear Sky, 0%)
     - `1`: 미세 비행운 (Contrail, 5%)
     - `2`: 고립된 권운 (Cirrus Fibratus, 10%)
     - `3`: 권적운 조각 (Cirrocumulus, 15%)
     - `4`: 권층운 박막 & 22° 무리 (Cirrostratus Veil & Halo, 20%)
     - `5`: 조각 뭉게구름 (Cumulus Humilis, 25%)
     - `6`: 전형적 뭉게구름 (Cumulus Mediocris, 30%)
     - `7`: 고적운 양떼구름 (Altocumulus, 38%)
     - `8`: 물결 고층운 (Altostratus Undulatus, 45%)
     - `9`: 웅대적운 (Cumulus Congestus, 52%)
     - `10`: 층적운 롤 & 빛내림 (Stratocumulus & Crepuscular Rays, 60%)
     - `11`: 층적운 군집 (Broken Stratocumulus, 65%)
     - `12`: 짙은 고층운 (Altostratus Opacus, 70%)
     - `13`: 웅대적운 & 중층운 복합층 (Towering Cumulus Veil, 75%)
     - `14`: 조각 층운 (Stratus Fractus, 80%)
     - `15`: 적란운 전조 (Cumulonimbus Calvus, 85%)
     - `16`: 대부분 흐림 (Mostly Overcast Stratus, 90%)
     - `17`: 난층운 진입 (Thick Nimbostratus, 94%)
     - `18`: 짙은 암회색 먹구름 (Dark Ominous Overcast, 97%)
     - `19`: 뇌우 적란운 (Severe Cumulonimbus Incus, 99%)
     - `20`: 온통 흐림 (100% Total Overcast, 100%)
   - **물리 광학 조명 (Mie Forward Scattering)**: 태양과 달 주위에 빛나는 실버라이닝(Silver Lining), 일출/일몰 황혼 붉은 노을 틴팅, 야간 은백색 달무리 반사.
   - **천체 자동 차폐 (Occlusion)**: 구름 두께에 따라 태양, 달, 별, 은하수, 렌즈 플레어의 투과율과 대기 산란광 실시간 감쇠.
   - **60fps 최적화 파이프라인**: 0.5x 하프 해상도 오프스크린 버퍼 연산 + 바이리니어 업스케일링 및 심리스 FBM 노이즈 사전 캐싱.
   - **풍속 & 풍향 제어**: 0x ~ 4x 풍속 슬라이더 및 8방위 풍향 제어.

4. **천문 관측 제어판 (Observatory Console)**
   - **일자 및 절기 선택**: 하지, 동지, 춘분, 추분, 보름달, 그믐달 프리셋 및 임의 날짜 선택 가능.
   - **실시간 태양/달 텔레메트리**: 고도, 방위각, 일출/일몰 시각, 적위, 월령, 월상 이름 및 조도 비율.
   - **은하수 & 항성계 정보**: 지방항성시(LST), 전천 회전각, 별빛 가시도, 천정/지평선 RGB 실시간 표시.
   - **관측지 위치 설정**: 충남과학고(공주), 서울, 도쿄, 그리니치 천문대, 적도, 북극 등 프리셋 및 위도/경도 직접 입력.
   - **수동 위성 발사**: 단일 위성 및 스타링크 14기 편대 즉시 발사 트리거.
   - **레이어 제어**: 구름 전체, 상층운, 중/하층운, 대기, 은하수, 태양, 달, 위성, 필름 그레인, 저사양 최적화 모드 각각 On/Off.

5. **키보드 단축키**
   - `Space`: 재생 / 일시정지
   - `H`: UI 숨기기 / 보이기 (Zen / Wallpaper 모드)
   - `F`: 전체화면 토글
   - `N`: 현재 로컬 시각 동기화
   - `C`: 주요 대표 구름 프리셋 순환 (0 -> 4 -> 6 -> 9 -> 10 -> 15 -> 19 -> 20)
   - `↑` / `↓`: 구름 단계 1단계 증가 / 감소
   - `S`: 인공위성 즉시 발사
   - `L`: 스타링크 편대 즉시 발사
   - `[` / `]`: 시뮬레이션 배속 감소 / 증가
